# Безопасность

## Токен и сеть

- Токен даёт доступ к Яндекс.Диску. Не отправляйте его в чаты, issue, pull request, скриншоты или логи. После восстановления отзовите доступ в Яндекс ID.
- Источники: `YADISK_TOKEN`, локальный файл `YADISK_TOKEN_FILE` / `token.txt`, либо поле локального веб-интерфейса. Аргумента командной строки с токеном нет.
- Веб-ввод хранится только в памяти процесса; поле очищается после отправки. База и HTTP-ответы токен не содержат. Пользовательский файл с токеном остаётся ответственностью пользователя.
- `rescue/api.py` отправляет токен только на разрешённые HTTPS-хосты под `yandex.ru`, `yandex.net`, `yandex.com`, `yandex.by`, `yandex.kz`. Проверяются исходная ссылка и редиректы. Подписанные ссылки оригиналов запрашиваются без OAuth-заголовка.
- В логах и состоянии хранятся категории ошибок; удалённые тела ответов и подписанные URL не записываются.
- Сервис слушает только `127.0.0.1`. Проверяются Host/Origin, сторонние origins запрещены. Изменяющие запросы, данные каталога и экспорт требуют секрет сессии, который хранится в памяти браузера. CORS не включён. Статические файлы и bootstrap доступны только с проверенным локальным Host.
- Это граница от посторонних веб-страниц, не защита от вредоносных программ на самом компьютере. Не публикуйте сервис через прокси. Сторонних серверов, CDN и телеметрии нет.

## Файлы и восстановление

- Облако используется только для чтения. `scan` и `compare` только читают локальные данные.
- Ядро находится в `rescue/`, CLI — `yd_rescue.py`. Общий загрузчик проверяет оригиналы по размеру и известному MD5; копии без облачного MD5 отмечаются как проверенные только по размеру.
- Запись ведётся относительно открытых дескрипторов папок, символические ссылки не обходятся. Облачные пути отображаются в безопасные локальные имена с суффиксами; отображение сохраняется в базе.
- Существующий несовпадающий файл не удаляется и не перезаписывается. Неуспешные временные файлы приложения удаляются при завершении попытки; после аварийной остановки могут остаться `.part`, которые не считаются готовыми копиями.
- Готовые копии публикуются атомарно без замены существующего имени. На macOS используется `renameatx_np(RENAME_EXCL)`. Проверка тома выполняется перед записью и между порциями данных; при замене или отсутствии тома запись приостанавливается.
- SQLite и журналы содержат приватный каталог файлов. Они остаются на внутреннем диске приложения. Каталог имеет права 0700; файлы состояния приватны. CSV и `.sqlite*` исключены из Git. Перед публикацией всё равно проверьте состав коммита.
- Имена из облака выводятся как текст. CSV-поля с признаками формул экранируются, оригинальные пути в базе не меняются.

## Границы проверки

Автотесты используют искусственные данные, подменённый транспорт и временные назначения. Они не подтверждают доступность конкретных файлов на Яндексе и исправность будущего внешнего накопителя. macOS — текущая целевая система; Windows и физический диск на 2 ТБ требуют отдельной проверки. Полностью недоступное серверное содержимое программа восстановить не может.
