# Yandex Disk Rescue

**Сохраняем важное с Яндекс.Диска на свой накопитель.**

Локальное приложение для macOS: получает каталог облака, скачивает доступные оригиналы и превью, проверяет сохранённые файлы и помогает продолжить восстановление после сбоя. Python, стандартная библиотека, без установки зависимостей.

## Что умеет

| Возможность | Для чего |
| --- | --- |
| Каталог облака | Получить список файлов, даже когда скачивание работает нестабильно |
| Выбор папок | Восстановить весь Диск или нужные папки с вложенными исключениями |
| Оригиналы и превью | Сохранить доступные оригиналы и отдельные уменьшенные копии изображений |
| Проверка результата | Сверить размер и MD5, если облако сообщает контрольную сумму |
| Пауза и продолжение | Сохранить очередь между запусками и дождаться возвращения накопителя |
| Просмотр результатов | Найти сохранённые файлы, открыть поддерживаемые медиа и выгрузить CSV |
| Настройки передачи | Изменить число загрузок, таймаут и интервал запросов |
| Командная строка | Сопоставить облако с локальными дисками и запускать восстановление из терминала |

Облако используется только для чтения. Приложение работает на вашем компьютере, без телеметрии и внешних CDN. Существующие несовпадающие локальные файлы не перезаписываются.

## Быстрый старт

```bash
git clone https://github.com/ivan-podgurskiy/yandex-disk-rescue.git
cd yandex-disk-rescue
python3 -m rescue
```

Откройте **http://127.0.0.1:8765** в браузере.

1. Подключите свой Яндекс.Диск с помощью OAuth-токена.
2. Нажмите **«Получить каталог»** — для этого внешний накопитель не нужен.
3. Создайте папку на накопителе, укажите её абсолютный путь и нажмите **«Проверить»**.
4. Выберите папки и начните восстановление.
5. Перед извлечением диска приостановите загрузку и дождитесь **«Активных записей нет»**.

Терминал должен оставаться открытым. Закрытие вкладки не останавливает загрузку; остановка сервиса — `Ctrl+C`. После перезапуска очередь сохраняется, скачивание возобновляется по кнопке.

Подробнее: [токен и подключение](docs/guide.md#токен), [работа с интерфейсом](docs/guide.md#локальный-веб-интерфейс-новая-версия), [команды CLI](docs/guide.md#быстрый-старт).

## Требования

- **macOS** — текущая целевая система; проверка накопителя использует `diskutil`.
- **Python 3.8+** — заявленный минимум; проверки разработки выполнены на Python 3.14. Python 3.8 и Windows отдельно не проверены.
- OAuth-токен своего Яндекс.Диска и свободное место для восстановленных данных.

**Статус: активная разработка.** Автотесты работают с искусственными данными. Они не подтверждают доступность ваших файлов на Яндексе или работу конкретного внешнего диска.

## Что важно знать

Программа сохраняет только то, что сервер сейчас отдаёт. Полностью недоступные файлы она восстановить не может. Превью — уменьшенная копия изображения, а не оригинал. Незавершённая передача файла при повторе начинается сначала.

Токен по умолчанию остаётся в памяти процесса. Если включить «Запомнить в SQLite на этом Mac», он сохраняется **открытым текстом** в приватной локальной базе. Каталог, база и CSV содержат личные данные. Не публикуйте их в Issues. Подробности — в [политике безопасности](SECURITY.md).

## Разработка

```bash
python3 -m unittest discover -s tests -v
node --check rescue/web/app.js
```

Для знакомства без аккаунта:

```bash
python3 tests/preview_app.py
```

Тестовый сервис доступен на **http://127.0.0.1:8766** и использует сгенерированные данные. Настоящий токен ему не нужен. Инструкции и временный путь назначения выводятся в терминал.

## English

A local macOS recovery app for Yandex.Disk, built with Python’s standard library. Browse the cloud catalog, select folders, rescue available originals and image previews, verify downloaded files, and resume the saved queue after restarting. Includes a browser UI and CLI tools for comparing cloud files with local drives.

Run `python3 -m rescue`, then open **http://127.0.0.1:8765**. Use your own OAuth token. The app reads the cloud without modifying it; there is no telemetry. It can only download content the server still serves. Previews are reduced images, not recovered originals. Windows and Python 3.8 have not been separately verified.
